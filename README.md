### Key Research Highlights:
- **Matrix:** Aliphatic Poly(urethane-urea) (PTMEG-1000 + IPDI)
- **Dynamic Crosslinker:** Bis(4-aminophenyl) disulfide (AFD, 12.8 wt%)
- **Reinforcement:** Silane-modified SiO2 nanoparticles (2.0 wt%)
- **Pencil Hardness:** 2H (ASTM D3363)
- **Critical Load Lc:** 9.5 N (+126% improvement over neat polymer)
- **Healing Efficiency:** 93.8% at 65°C for 60 minutes
- **Durability:** >86.5% efficiency retention over 10 consecutive scratch cycles
